Классическая игра "виселица" на WPF, ОС Windows 7+.

**Имеется два режима игры:** игра с другом, вопрос от компьютера.

**Ограничение:** только русский язык и запрет на любые символы для ответа, лимит в 140 символов для вопроса.

❗ В качестве ответа можно указывать целые словосочетания (разрешен пробел), но это не учитывается в алгоритме при отгадывании. Это приводит к тому, что если в ответе есть пробел - это всегда поражение.

<img src="https://github.com/user-attachments/assets/b62bf021-a9ba-4263-8c86-94bb4f78399e" width="500" height="400">

По умолчанию установлено 9 вопросов, которые выбираются случайно из question.txt файла.

Для расширения пула вопросов отредактируйте answer.txt и question.txt файла (bin/Debug папка в проекте).
Важно, чтобы строка вопроса совпадала со строкой ответа - алгоритм проверяет соответствие по индексу случайно взятого вопроса.
